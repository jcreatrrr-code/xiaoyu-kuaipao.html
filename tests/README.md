# 《小鱼快跑》测试脚本（v1.0.0 时的状态）

这些脚本用 Python + Playwright 打开游戏文件，通过游戏里的测试钩子模拟玩家。
脚本里的游戏路径写的是 /mnt/user-data/outputs/xiaoyu-kuaipao.html，换环境后需要改成实际路径。

| 文件 | 检查什么 |
|---|---|
| t15.py | 页面能否加载、有没有脚本报错（最基本的冒烟测试） |
| t5c.py | 通用的“自动通关”机器人，被其他脚本引用 |
| t24.py | 第 8–12 关在竖屏和横屏下能否通关 |
| t33.py | 扫描全部关卡：检查点是否卡在按钮和石门之间、目标物数量是否够 |
| t35.py | 第 5 关喂食 Boss 战的模拟 |
| t40.py | 第 3、9、12 关三场 Boss 战的模拟 |
| t22.py / t42.py | 小馆营业：挂机与认真参与的收入对比 |
| t26.py | 主菜单、选关、杂货铺、小馆各标签页的点击流程 |
| t28.py | 奇珍书各分类的显示 |
| t43.py – t46.py | 小馆等级、菜谱展开、困难模式解锁、十项调整的综合检查 |

注意：这些机器人躲避冲刺和跟踪目标比真人准，但不会认错、不会手忙，
所以它们测出来的难度只是参考，不能代替真人试玩。

## 现在的用法（v1.3.0 起）

脚本已放进仓库，游戏路径改为自动指向仓库里的游戏，不用再手动改。

- 全部运行：`python3 tests/run_all.py`
- 只跑几个：`python3 tests/run_all.py t15 t33`

`run_all.py` 会先用 `src/` 拼出一份游戏再测，所以测的就是改过的源文件。
脚本出错退出才算失败；大多数脚本只打印模拟结果，数字好不好仍要人看。
t26、t43 在 v1.0.0 时就已经跟不上游戏的改动，失败只作参考。
